# GitHub sweep: 2026 alpha-factor mining with LLMs and RL — 2026-11-05

This targeted sweep covers repositories **created on or after 2026-01-01** that use LLMs or reinforcement learning to discover, evolve, or screen trading alpha factors. Thirty-six GitHub repository searches (English and Chinese keywords, plus the `alpha-mining`, `factor-mining`, `alpha-factors`, and `factor-investing` topics) were combined with a literature search for 2026 alpha-mining papers and their official code. Entries were screened against [CONTRIBUTING.md](../../CONTRIBUTING.md). Descriptions follow each repository's README, and paper identifiers were checked against arXiv and ICLR listings. This is documentation review, not reproduction.

QuantaAlpha and FactorMiner were already added in the previous 2026 sweep, and AgonAlpha was already listed under Research Papers.

## Observations

- Most 2026 repositories matching "alpha/factor mining" automate WorldQuant BRAIN submissions, package agent "skills," fork Qlib or RD-Agent into retail platforms, or mirror other projects. Research code with a paper is a small minority, and it tends to have low star counts.
- Reinforcement learning now appears mainly as **fine-tuning the LLM that writes factors** (QuantEvolver, AlphaAgentEvo, and the late-2025 Alpha-R1). Earlier work instead trained RL policies that generate formulas directly.

## Considered and not added

- **imbue-bit/AlphaGPT** (most-starred 2026 result): the README has no technical documentation, and the code is oriented to Solana DEX token trading (Birdeye, DexScreener, and Jupiter execution). Several copies and mirrors exist.
- **FinStep-AI/Alpha-R1**: relevant (alpha screening with LLM reasoning trained by RL), but the repository was created in December 2025, outside this sweep's window. Candidate for a general pass.
- **hongha5192-bit/AlphaAgentEvo**: a third-party reimplementation, not the authors' code.
- **QuantMind, LLM_QUANT_FACTORY, AlphaPilot, alpha-mining-system, quantlab-oss**: Qlib/RD-Agent-based platforms for A-shares with no paper or distinct method beyond already-listed projects.
- **EvoQuant**: a self-evolving agent that reproduces broker research reports. It is interesting but has no paper or evaluation yet. Revisit.
- **alpha-foundry** (typed GP + GFlowNet with C++ kernels), **Evolutionary-Alpha-Miner**, **aurumq-rl** (PPO stock selection with documented ablations; license unclear), **openfactor** (risk model with LLM exposures): credible but very new with low adoption. Revisit.
- **QuantGPT, worldquant-miner, wq-alpha-agent, worldquant-alpha-crew, and similar**: WorldQuant BRAIN submission automation.
- **CogAlpha** (ACL 2026 Oral): only a prompt-template repository is public.
- **Agentic Quantitative Trading survey** (arXiv 2608.31041) and **FaVOR** (arXiv 2608.30192): no GitHub repository located.
